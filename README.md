# 📊 HR Analytics Dashboard: Employee Attrition Analysis

## 📌 Project Overview

This project focuses on analyzing employee data to identify key factors contributing to employee attrition.
An interactive dashboard was built to uncover trends, patterns, and insights that can help organizations improve employee retention.

---

## 🎯 Objective

* Analyze employee data to understand attrition patterns
* Identify key drivers such as salary, satisfaction, and department
* Build an interactive dashboard for data-driven decision making

---

## 📂 Dataset

* HR Analytics Dataset (Kaggle)
* Contains employee details such as:

  * Department
  * Salary Level
  * Satisfaction Score
  * Years at Company
  * Attrition Status

---

## 🛠 Tools & Technologies Used

* **Excel** → Data Cleaning
* **SQL** → Data Analysis
* **Power BI** → Dashboard & Visualization

---

## 📊 Dashboard Features

### 🔹 KPI Metrics

* Total Employees
* Attrition Count
* Attrition Rate (%)
* Salary Index (Average)

### 🔹 Visualizations

* Attrition Rate by Years at Company
* Attrition by Department
* Attrition Rate by Salary Level
* Attrition vs Satisfaction Level
* Scatter Plot (Evaluation vs Attrition)

### 🔹 Filters

* Department
* Salary Level

---

## 📈 Key Insights

* Employees with **low salary show highest attrition (~30%)**, indicating compensation is a major factor
* **Sales department has the highest attrition**, followed by technical roles
* Employees with **low satisfaction levels are more likely to leave**, showing strong correlation
* Attrition peaks around **5 years of experience**, indicating mid-career drop-off
* Employees with **higher salary show significantly lower attrition**, improving retention
